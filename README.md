## 🇺🇸 English

### Overview
**Groogp** is a premium, high-performance messaging application built with a focus on speed, security, and a Telegram-like user experience. It features real-time communication, advanced media handling, and a sleek, responsive interface.

### ✨ Key Features
- 📱 **Real-time Chat**: Lightning-fast messaging using WebSockets.
- 👥 **Groups & Channels**: Create communities or private group chats with ease.
- 🔒 **Secure Auth**: JWT-based authentication with Bcrypt password hashing.
- ️ **Media Hub**: Full-screen viewer for Image/Video/Audio with lazy loading.
- 🔥 **Advanced Messaging**: Smart Emoji support (Twemoji), Reply system, and Selection Mode.
- 🎨 **Premium UI**: Pure Vanilla CSS design with Glassmorphism and smooth animations.

### 🛠️ Tech Stack
- **Backend**: Node.js, Express, WS (WebSockets).
- **Database**: SQLite3 (Optimized).
- **Frontend**: Vanilla JavaScript (ES6+), Modern CSS3.

### 🚀 Getting Started
```bash
# Clone and install
git clone https://github.com/yourusername/groogp.git
npm install

# Run dev server
npm run dev
```

## 🇮🇷 فارسی

### معرفی پروژه
**گروگپ (Groogp)** یک پلتفرم پیام‌رسان مدرن و حرفه‌ای است که با تمرکز بر سرعت، امنیت و تجربه کاربری مشابه تلگرام طراحی شده است. این اپلیکیشن از ارتباطات در لحظه (Real-time)، مدیریت پیشرفته رسانه‌ها و رابط کاربری شیک و واکنش‌گرا بهره می‌برد.

### ✨ قابلیت‌های کلیدی
- 📱 **چت در لحظه**: ارسال و دریافت فوق سریع پیام‌ها با استفاده از WebSockets.
- 👥 **گروه‌ها و کانال‌ها**: قابلیت ساخت جوامع آنلاین یا گروه‌های خصوصی.
- 🔒 **امنیت بالا**: احراز هویت مبتنی بر JWT و رمزنگاری پسوردها با Bcrypt.
- 🖼️ **مدیریت رسانه**: نمایشگر تمام‌صفحه تصاویر، ویدیوها و فایل‌های صوتی با قابلیت Lazy Loading.
- 🔥 **پیام‌رسانی پیشرفته**: پشتیبانی هوشمند از ایموجی‌ها (Twemoji)، سیستم پاسخ (Reply) و حالت انتخاب پیام.
- 🎨 **رابط کاربری پریمیوم**: طراحی کاملاً Vanilla CSS با افکت‌های شیشه‌ای (Glassmorphism) و انیمیشن‌های نرم.

### 🛠️ پشته تکنولوژی
- **بک‌اند**: Node.js, Express, WS (WebSockets).
- **دیتابیس**: SQLite3 (بهینه‌سازی شده برای عملکرد بالا).
- **فرانت‌‌اند**: Vanilla JavaScript (ES6+), Modern CSS3.
